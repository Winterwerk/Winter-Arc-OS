WINTER ARC OS 2.3 – INSTALLATION AUF DEM IPHONE
=============================================

1. VORHER DATEN SICHERN
   - Öffne die alte WINTER-ARC-App.
   - Mehr → Backup → Backup exportieren.
   - Sichere die persönliche JSON-Datei außerhalb der App unter Dateien.
   - Wenn du in der alten App noch neue Trainingsdaten hast, hat dieses aktuelle Backup Vorrang.

2. APP-PAKET HERUNTERLADEN
   - Das ZIP „winterarc-2.3.zip“ aus ChatGPT laden.
   - Wenn der Download in der ChatGPT-iPhone-App nicht geht, dieselbe Unterhaltung in Safari unter chatgpt.com öffnen.
   - In „Dateien → Downloads“ die ZIP-Datei einmal antippen; der Ordner wird entpackt.

3. GITHUB AKTUALISIEREN
   - https://github.com/Winterwerk/Winter-Arc-OS öffnen.
   - Branch „main“ wählen.
   - Add file → Upload files (evtl. Desktop-Website in Safari anfordern).
   - ALLE Dateien AUS dem entpackten Ordner auswählen (nicht nur die ZIP und nicht den Ordner als Unterordner hochladen).
   - Wichtig: app.js, library.js, training-tools.js, lexicon.js, data.js, store.js, strength.js, style.css, atlas.js, charts.js, sw.js, index.html, manifest.webmanifest und Icons gehören ins Hauptverzeichnis.
   - Gleichnamige vorhandene Dateien ersetzen und „Commit changes“ bestätigen.
   - Persönliches JSON-Backup NIEMALS auf GitHub hochladen.

4. APP STARTEN
   - Settings → Pages: main / (root) überprüfen.
   - Die GitHub-Pages-URL öffnen, in diesem Projekt normalerweise:
     https://winterwerk.github.io/Winter-Arc-OS/
   - Die Kopfzeile muss V2.3.0 anzeigen.
   - Wenn noch 2.1/2.2 erscheint, Seite neu laden, Safari neu starten und bei Bedarf das Home-Bildschirm-Icon neu erstellen. Die Backups vorher sichern.
   - Safari Teilen → Zum Home-Bildschirm hinzufügen.

5. KURZTEST
   - Training → Tag A: „Letzte Werte“ und + Satz testen.
   - Übung mit ↑/↓ verschieben, überspringen, wiederherstellen.
   - Bei einer Übung Einstellungen öffnen: individuelle Pause und persönliche Notiz testen.
   - Einen Arbeitssatz mit gültigem Gewicht/Wiederholungen abhaken: Timer startet.
   - Mehr → Plan → Vorlagen und Bibliothek öffnen. Vorlage nur aktivieren, wenn du deinen bisherigen Plan ersetzen willst.
   - Analyse: Kraftrekorde, 30/90/180/Gesamt und Trainingshistorie prüfen.
   - Training abschließen erst, wenn die echte Einheit tatsächlich beendet ist.

6. DATENKONTROLLE
   - Sind deine alten Workouts und Körpermesswerte vorhanden? Dann NICHT unnötig importieren.
   - Fehlen sie: Mehr → Backup → JSON importieren → dein persönliches Backup auswählen.
   - Achtung: Ein Import ERSETZT den aktuellen lokalen Datenbestand, er ergänzt ihn nicht.
   - Safari und eine Home-Bildschirm-PWA können unterschiedliche Speicherkontexte haben; deswegen Backup und Import nutzen.

DATENSCHUTZ
Das Repo ist öffentlich, die persönlichen Trainingsdaten gehören ausschließlich in die App oder dein privates Backup. Keine Körperwerte oder JSON-Dateien ins Repository hochladen.

TECHNIK
Die neue App speichert weiterhin unter dem lokalen Schlüssel winterArcOS_v2. Ein Update verändert die alten gespeicherten Einheiten nicht; deine manuell gewählten Planvorlagen verändern ausschließlich zukünftige Einheiten.
